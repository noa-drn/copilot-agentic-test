# Agent rules

Durable rules for any agent working in this repo. Read this before acting.

## Task

Implement `upcomingTodos` in `src/main/kotlin/com/noaduron/todo/TodoService.kt`.
The full spec is in `docs/ISSUE.md` and `README.md`. Do not modify the tests.

## Definition of done

- `./gradlew test` is green (all tests in `TodoServiceTest.kt` pass).
- The code follows the delivery standards in `README.md` (style, commit format, PR sections).

## How to work

- Make one bounded change for this task only. Do not touch unrelated files.
- Run `./gradlew test` and iterate until it passes. Report what you did, what blocked
  you, and whether tests pass.
- Commit with a short imperative subject (max 50 chars), no AI attribution.
- Keep the diff small and reviewable.
